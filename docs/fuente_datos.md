# Fuente de datos

## Dataset principal

Órdenes de Compra y/o Servicios de las entidades.

## Entidad publicadora

Organismo Especializado para las Contrataciones Públicas Eficientes — OECE.

## Fuente

Plataforma Nacional de Datos Abiertos del Perú.

## Periodo utilizado

Enero a junio de 2026.

## Uso en MYPE Radar

Los registros serán utilizados para analizar:

- Descripciones de bienes y servicios.
- Entidades públicas contratantes.
- Cantidad de órdenes.
- Montos históricos.
- Departamentos.
- Fechas y periodos de compra.
- Tendencias asociadas al perfil de una MYPE.

## Limitación

Los registros son históricos y no deben interpretarse como licitaciones actualmente abiertas.
